# 财经审稿台 1.4

[打开公开网站](https://wwf2003414-wq.github.io/finance-review-desk/)。也可以下载 [index.html](index.html) 后双击离线使用。稿件与替换选择在当前页面处理，浏览器只保存主题偏好。

1. 把财经口播、标题、字幕或笔记粘贴到左栏，并选择发布平台与场景。
2. 在「选择替换词」中逐处勾选，编辑预填建议或填写自己的措辞。同一个词出现多次时，可以分别处理。
3. 对照右栏，再点「复制版本」。取消勾选或留空会保留原词。两个词条重叠时，只应用最后勾选的一处。

检测使用本地语境规则和 221 条词汇对照，评分与评语按原稿计算。改写前核实事实、主体与来源，并如实处理实际的服务、交易引导和利益关系。

页面是单文件静态应用。内嵌 GSAP 用于仪表和入场动画，动画遵循系统的减少动态效果设置。评语聚光和计分过渡参考 React Bits，工作区布局参考 Taste Skill。
