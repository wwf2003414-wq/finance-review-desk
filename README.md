# 财经审稿台 1.2

在浏览器内初筛财经口播、标题、字幕和笔记。粘贴原稿后，选择发布平台与场景，查看风险指数、命中原句和改稿建议。

打开 [index.html](index.html) 即可离线使用。页面会在当前浏览器内分析稿件，并只保存深浅主题偏好。检测基线沿用原版，结果用于辅助人工复核。

页面是单文件静态应用。内嵌 GSAP 用于仪表和入场动画，动画遵循系统的减少动态效果设置。评语聚光和计分过渡参考 React Bits，工作区布局参考 Taste Skill。

- [React Bits](https://github.com/DavidHDev/react-bits)
- [Taste Skill](https://github.com/Leonxlnx/taste-skill)
