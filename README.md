# 财经审稿台 1.3

在浏览器内初筛财经口播、标题、字幕和笔记。粘贴原稿后，选择发布平台与场景，查看风险指数、命中原句和改稿建议。

[打开公开网站](https://wwf2003414-wq.github.io/finance-review-desk/)。双击下载后的 [index.html](index.html) 也可离线使用。稿件在当前浏览器内处理，页面只保存深浅主题偏好。

v1.3 加入 221 条语境词汇对照。命中适用的语境时，可在评语里查看「语境改写参考」。普通术语按表达提示处理。改写前核实事实、主体与来源，实际服务、交易引导和利益关系也需要如实处理。检测结果用于辅助人工复核。

页面是单文件静态应用。内嵌 GSAP 用于仪表和入场动画，动画遵循系统的减少动态效果设置。评语聚光和计分过渡参考 React Bits，工作区布局参考 Taste Skill。
